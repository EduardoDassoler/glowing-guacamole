## 📚 Matéria: Gerenciamento de Projetos de Software

### 🎯 Conceitos Importantes Estudados
*   **Portfólio:** É o mapa estratégico da empresa. Serve para a diretoria decidir para onde ir e quais projetos valem a pena investir para atingir as metas do negócio.
*   **Programa:** Um grupo de projetos relacionados que têm um objetivo comum.
*   **Projeto:** O canteiro de obras para construir uma solução específica (como um software), com início, meio e fim.
*   **Subprojeto:** A divisão do projeto em partes menores para facilitar o trabalho da equipe no dia a dia.
